What I build

  • iOS and Android from one codebase, with Expo by default and custom native modules when the app needs them.
  • Offline-first apps that save to SQLite on the device and sync when the connection comes back.
  • Native features: calls through CallKit and Android Telecom, push notifications, maps, and in-app purchases with RevenueCat or Stripe.
  • The backend behind the app: Node.js or Python APIs, Supabase or PostgreSQL, real-time chat and video.
  • Release pipelines: EAS builds, TestFlight and Play testing tracks, and checks that stop a release with mismatched version numbers.
  • Rescue work: crashes, slow lists, stuck Expo SDK upgrades and the move to the New Architecture.

Who this is for

You’ll get the most out of working with me if:

  • You’re a founder who wants one person to own the app, the API and the release, instead of three vendors pointing at each other.
  • You have an app that crashes, drags or is stuck on an old Expo SDK, and you need someone who reads native crash logs.
  • Your users work with bad signal: field staff, clinics, warehouses, rural areas.
  • You’re adding AI to a mobile app and want answers that stream in, not a spinner. (See AI app development.)

I’m probably not the right fit if you need a large design team or an agency with account managers.

Questions clients ask

How much does a React Native app cost?

Projects start from $3,000 for a focused first version, and hourly work is $25–40/hr. The price depends on how many screens and user roles there are, whether you need a backend, native features like calling or payments, and offline support. You get a written estimate before any work starts.

How long does it take to build a React Native app?

A focused app with one core flow takes weeks, not months. Bigger platforms take longer: Baba Telehealth, with video visits, billing and an admin side, was scoped at 14 weeks. I'll give you a timeline with the estimate.

Should my app use Expo or bare React Native?

Expo, for most new apps. EAS builds, over-the-air updates and simpler SDK upgrades save real time. I add custom native code when an app needs something Expo doesn't cover, such as deep CallKit integration.

Do you publish apps to the App Store and Google Play?

Yes. I've published 70+ apps. I set up the store listings, TestFlight and Play testing tracks, and handle review feedback from Apple and Google until the app is live.

Can you take over or fix an existing React Native app?

Yes. Crash fixes, slow screens, Expo SDK upgrades and moving to the New Architecture are common requests. On ChartVision I tracked an iOS crash down to the exact commit with git bisect before fixing it.

Which time zone do you work in?

Karachi, Pakistan (UTC+5). You get written updates every week and calls scheduled in your time zone.

Tell me about your app

A short paragraph is enough: what it should do, who uses it, and when you need it. I reply within a day with questions or a rough estimate.
